# Aura Fashion – WooCommerce Theme v1.9.0

Premium black & soft-gold fashion WooCommerce theme with a full shopping, marketing, account, and admin stack.

---

## What’s new in v1.9

- **Rich demo import**: 12 simple products + 1 variable product (Size/Color swatches), 5 categories, coupons (`AURA10`, `WELCOME15`, `FREESHIP`), 3 lookbooks, 3 journal posts, pages, menu, default options
- **UI polish**: refined product-card hover, pill badges, swatch focus rings, free-shipping bar, skeleton shimmer, sticky mobile ATC, light-mode tweaks
- **TESTING.md**: complete feature-by-feature checklist so you can verify every feature

## Admin & Store Management

| Feature | How to use |
|---------|------------|
| **Theme options panel** | WP Admin → **Aura Options** – store notice, free shipping threshold, exit popup, mega menu, loyalty, GA4 ID, Meta Pixel ID |
| **Custom product badges** | Product edit → **Aura Badges** (New, Bestseller, Limited, Eco). Auto-New by publish age; auto-Bestseller by total sales |
| **Bulk product import guidance** | Aura Options → **Bulk Import Guide** |
| **Analytics integration** | Paste GA4 + Meta Pixel in Aura Options; purchase events on thank-you page |

## Install

1. Upload and activate **Aura Fashion** + **WooCommerce**.  
2. **Appearance → Aura Demo Import** → Import Full Demo Content.  
3. **Settings → Permalinks → Save**.  
4. **Aura Options** → set notice, shipping threshold (`100`), exit code (`AURA10`), analytics IDs.  
5. **Appearance → Customize** → logo, hero, colors.  
6. Confirm coupons `AURA10` / `WELCOME15` exist (created by demo import).

## How to test all features

Open **TESTING.md** in the theme folder. It is a complete checklist covering:

1. Homepage & design (hero, dark mode, mega menu)  
2. Shop & AJAX filters  
3. Quick View, AJAX cart, wishlist  
4. Single product (swatches, size guide, stock/sale countdown, sticky ATC)  
5. Cart & checkout (free shipping bar, coupons)  
6. Account (addresses, Buy Again, order tracking, size profile)  
7. Marketing (exit popup, newsletter)  
8. Lookbook & Style Journal  
9. Static pages & 404  
10. Admin options & badges  
11. Performance/SEO spot checks  

**Demo highlights for testing**
