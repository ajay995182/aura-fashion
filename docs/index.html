How Aura-Fashion was built and how to test it

Aura-Fashion is my first WordPress website, built after finishing a WordPress course. This guide shows what the store is made of, which parts are plugins, how the custom theme was made with AI help, and a step-by-step checklist to test every feature.

The custom theme

How the Aura Fashion theme was made

The theme is the only part written with AI models. I decided what the store needed, the AI wrote and refined the code, and I installed, tested and corrected the result.

The process

  1. 1
    Decide the idea and featuresA fashion store with a black and gold look, plus shopping extras such as Quick View, wishlist and filters.
  2. 2
    Ask AI models to write the code AIPHP, CSS and JavaScript files for the theme, built up feature by feature.
  3. 3
    Install it in WordPressZip the theme folder and upload it under Appearance → Themes.
  4. 4
    Add test contentImport demo products, coupons and pages so every feature has something to work on.
  5. 5
    Test and fixGo through the checklist below, spot problems such as overlapping badges, and correct them.
  6. 6
    Add the pluginsInstall payments, email, caching and security plugins around the theme.

Set up your own copy

Install it step by step

Follow these in order. WooCommerce must be active before the demo import runs.

1Install WordPress

Use your host's WordPress installer. Needs WordPress 6.0+ and PHP 7.4+.

2Install WooCommerce

Plugins → Add New → WooCommerce → Install → Activate. Run its setup wizard and choose Indian Rupee.

3Upload the theme

Appearance → Themes → Add New → Upload Theme → choose aura-fashion-v1.10.6.zip → Install → Activate.

4Save permalinks

Settings → Permalinks → Save Changes.

5Check the WooCommerce pages

WooCommerce → Status → Tools → Create default WooCommerce pages (only if Shop, Cart, Checkout or My Account are missing).

6Import the demo content

Appearance → Aura Demo Import → Import Full Demo Content. This creates the test products and pages.

7Assign the menus

Appearance → Menus → set Primary Menu and Footer Menu.

8Set Aura Options and the Customizer

Aura Options: notice, free shipping amount, exit code, analytics IDs. Appearance → Customize: logo, hero, colours.

9Install the plugins

Jetpack, WP Mail SMTP, WP Mail Logging, W3 Total Cache, Loginizer Security and a payments plugin. Then configure each one.

Demo data

What is real and what is for testing

The software and the design are real. The shop content is only there so the workflow can be tested.

  • 12 simple products + 1 variable productCreated by the demo import so the shop has something to show.
  • Prices, sale dates and stock numbersMade up. They exist to trigger features like "Only X left" and the sale countdown.
  • Product photosPlaceholder images that do not match the product names. A real shop would use its own photos.
  • Coupons AURA10, WELCOME15, FREESHIPTest codes only.
  • Orders and paymentsTest mode only. No real money is taken and nothing is shipped.
